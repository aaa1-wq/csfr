6.8 有一个分数序列:2/1,3/2,5/3,8/5……求出这个数列的前20项之和.
解: main()
{
int n,t,number=20;
float a=2,b=1,s=0;
for(n=1;n<=number;n++)
{
s=s+a/b;
t=a,a=a+b,b=t;
}
printf("总和=%9.6f\n",s);
}
