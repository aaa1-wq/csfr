# 第二章 §4 收敛准则 —— 内容总结

## 一、单调有界数列收敛定理

**定理 2.4.1**：单调有界数列必定收敛（单调增有上界 → 收敛于上确界；单调减有下界 → 收敛于下确界）。

**意义**：无需事先知道极限值即可判断数列收敛性，是研究递推数列敛散性的核心工具。

**典型例题**：
- **例2.4.1**：$x_{n+1}=1+\dfrac{x_n}{1+x_n}$，证明收敛并求极限 $\dfrac{1+\sqrt5}{2}$（黄金分割数）。
- **例2.4.2**：$x_{n+1}=x_n(1-x_n)$，收敛于 0，且 $\lim nx_n=1$（用 Stolz 定理）。
- **例2.4.3**：$x_{n+1}=\sqrt{3+2x_n}$，收敛于 3。
- **例2.4.4**：Fibonacci 数列与兔群增长率——增长率数列 $b_n=a_{n+1}/a_n$ 虽不单调，但奇偶子列分别单调，最终收敛于同一极限 $\dfrac{1+\sqrt5}{2}\approx1.618$（黄金比例）。
- **例2.4.5**：单位圆内接正 $n$ 边形半周长 $L_n=n\sin\frac{180°}{n}$ 单调增有上界，其极限定义为 $\pi$。
- **例2.4.6**：$(1+\frac1n)^n$ 单调增，$(1+\frac1n)^{n+1}$ 单调减，两者极限相同，定义为 **e**。
- **例2.4.7**：$p$-级数型数列 $a_n=\sum \frac{1}{k^p}$：$p>1$ 收敛，$0<p\le1$ 发散（正无穷大量）。
- **例2.4.8**：$b_n=1+\frac12+\cdots+\frac1n-\ln n$ 收敛于 **Euler 常数** $\gamma\approx0.5772$。
- **例2.4.9、2.4.10**：由此推出 $\sum\frac{1}{n+k}\to\ln2$，交错调和级数部分和 $\to\ln2$。

## 二、闭区间套定理

**定义 2.4.1**：闭区间列 $\{[a_n,b_n]\}$ 满足包含关系 $[a_{n+1},b_{n+1}]\subset[a_n,b_n]$ 且长度 $b_n-a_n\to0$，称为闭区间套。

**定理 2.4.2**：闭区间套必存在唯一公共点 $\xi=\lim a_n=\lim b_n$。

**应用——定理 2.4.3**：实数集 $\mathbb{R}$ 不可列（反证法，利用三等分区间套构造矛盾）。

## 三、子列与 Bolzano–Weierstrass 定理

**定义 2.4.2**：子列 $\{x_{n_k}\}$（下标严格单调递增）。

**定理 2.4.4**：原数列收敛 ⟹ 任何子列收敛于同一极限。
**推论**：若存在两个子列收敛于不同极限，则原数列发散（**例2.4.11**：$\sin\frac{n\pi}{4}$ 发散）。

**定理 2.4.5（B-W 定理）**：有界数列必有收敛子列（证明用二分法构造闭区间套）。

**定理 2.4.6**：无界数列必有子列趋于 $\infty$。

## 四、Cauchy 收敛原理

**定义 2.4.3**：基本数列（Cauchy列）：$\forall\varepsilon>0,\exists N,\forall n,m>N: |x_n-x_m|<\varepsilon$。

**定理 2.4.7**：数列收敛 ⟺ 是基本数列（充分性证明：基本列有界 → B-W定理取收敛子列 → 证明全列收敛于同一极限）。

- **例2.4.12**：$x_n=1+\frac{1}{2^2}+\cdots+\frac{1}{n^2}$ 是基本数列（用裂项放缩）。
- **例2.4.13**：$x_n=1+\frac12+\cdots+\frac1n$ 不是基本数列（调和级数发散）。
- **例2.4.14**：压缩映射条件 $|x_{n+1}-x_n|\le k|x_n-x_{n-1}|\ (0<k<1)$ ⟹ 数列收敛。

**意义**：Cauchy 收敛原理体现了**实数系的完备性**——注意有理数集不具有完备性（如 $(1+1/n)^n$ 是有理数基本列，但极限 e 是无理数）。

## 五、实数系基本定理的等价关系

五个定理互相等价，形成逻辑链：

```
确界存在定理
      ⇓
单调有界数列收敛定理
      ⇓
闭区间套定理
      ⇓
Bolzano-Weierstrass 定理
      ⇓
Cauchy 收敛原理
```

**定理 2.4.8**：进一步证明 Cauchy收敛原理 ⇒ 闭区间套定理 ⇒ 确界存在定理，从而形成闭环，说明**实数系的完备性与连续性等价**——五个定理彼此等价，均可称为"实数系的基本定理"。

## 六、核心思想脉络

| 概念 | 作用 |
|---|---|
| 确界存在定理 | 实数系连续性的起点 |
| 单调有界收敛 | 无需先知极限，判断收敛的实用工具 |
| 闭区间套 | 构造性方法，证明实数不可列、B-W定理等 |
| 子列 | 判断发散的工具（两子列极限不同） |
| Cauchy准则 | 脱离"猜极限"，纯粹用数列自身特征判断敛散性；体现完备性 |

这一节从"单调有界必收敛"出发，逐步引出圆周率 $\pi$、自然常数 $e$、Euler常数 $\gamma$ 等重要常数的严格定义，并建立了实数系五大基本定理的等价体系。
